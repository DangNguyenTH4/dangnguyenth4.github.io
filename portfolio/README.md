# 3D Interactive Portfolio with Three.js & Planet Mindset

![Portfolio Preview](preview.gif)  
*A visually stunning, interactive 3D portfolio powered by Three.js, embodying the "Planet Mindset" philosophy — expansive, interconnected, and orbiting around creativity, innovation, and exploration.*

---

## 🌍 Overview

This portfolio transforms the traditional 2D resume into a **3D cosmic journey**. Using **Three.js**, users navigate through a solar system where each **planet represents a core aspect of your professional identity**:

- 🌟 **Skills Planet** – Orbiting skill nodes with interactive tooltips
- 🚀 **Projects Planet** – Clickable project moons with live demos & GitHub links
- 🧑‍💻 **Experience Planet** – Timeline rings showing career progression
- 📫 **Contact Planet** – Interactive form with particle effects
- 🌌 **About Me Nebula** – A glowing cloud of interests, values, and personality

The **"Planet Mindset"** reflects a holistic, boundaryless approach to personal branding — just as planets are part of a larger system, your skills, projects, and story are interconnected in a dynamic ecosystem.

---

## ✨ Features

- Fully **interactive 3D environment** with orbit controls
- **Responsive design** – works on desktop, tablet, and mobile
- **Dynamic camera transitions** between planets
- **Particle systems** and **post-processing effects** (bloom, glow)
- **Real-time animations** using GSAP + Three.js
- **Project modals** with embedded previews (YouTube, CodePen, etc.)
- **Dark mode cosmic aesthetic** with nebula backgrounds
- **SEO-friendly fallback** with meta tags and structured data
